# Code of conduct

tiny-eye adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project, in every project
space (issues, pull requests, discussions, reviews) and when representing the project elsewhere.

## In short

- Be welcoming, kind and respectful, including when you disagree.
- Give and accept constructive feedback gracefully; focus on what is best for the community.
- Take responsibility for mistakes, apologize to those affected and learn from them.
- Harassment, insults, sexualized language or imagery, personal or political attacks, and
  publishing others' private information without permission are not acceptable.

The full text of the Contributor Covenant 2.1 is the binding version.

## Enforcement

Report unacceptable behaviour to **the maintainers via GitHub private reporting** (the
repository's Security → Advisories → Report a vulnerability form, which reaches only the
maintainers). All reports are reviewed and investigated promptly and fairly, and the privacy and
safety of the reporter are respected.

Maintainers follow the Contributor Covenant's enforcement guidelines (correction, warning,
temporary ban, permanent ban) when deciding on consequences.
